# Instruções

## Controles básicos de câmera

Segurar com o botão direito do mouse, sem ser em cima de um palito, permite controlar a câmera. Rodar o *scroll* do mouse adiciona ou remove zoom.

## Menu principal

![alt text](/docs/images/image.png)

- **Alternar visualização (2D/3D):** Alterna a projeção da câmera entre 2D e 3D.
- **Adicionar novo palito:** Insere um novo palito na simulação.
- **Analisar cargas:** Se houver pelo menos três (03) palitos unidos na simulação, calcula-se, a partir do método da rigidez direta, as forças internas da estrutura, tendo como resultado final a estrutura sob deformação. Caso a estrutura seja montada de modo a não suportar a carga, todos os elementos ficarão somente de coloração preta.
- **Distância entre camadas:** Distância entre as duas camadas da estrutura.

## Menu do palito

Ao clicar com o botão direito do mouse sob algum palito qualquer, abre-se o menu de contexto do respectivo palito, contendo propriedades sobre o mesmo.

![alt text](/docs/images/image0.png)

- **Ângulo:** Permite alterar o ângulo do palito, fazendo-o rotacionar em torno do próprio eixo.
- **Comprimento:** Permite alterar a escala de comprimento do palito.
- **Separar palito:** Permite separar um palito de um grupo.
- **Excluir palito:** Permite excluir um palito qualquer.
